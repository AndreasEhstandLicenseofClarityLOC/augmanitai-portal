# Security Policy

This repository is a static research portal (HTML + metadata). It runs no
server-side code and processes no user data.

## Reporting a vulnerability

If you discover a security or privacy issue (for example, an exposed credential,
a misconfiguration, or a content-integrity problem), please report it
**privately and responsibly**:

- Email: **ehstand.schule@gmail.com**
- Subject line: `SECURITY — augmanitai-portal`

Please include:
- a description of the issue,
- steps to reproduce (if applicable),
- the affected URL or file.

## What to expect

- Acknowledgement as soon as possible.
- Please allow reasonable time to address the issue before any public disclosure.
- Do not exploit the issue beyond what is necessary to demonstrate it, and do not
  access, modify, or delete data that is not yours.

## Scope

In scope: this repository and the pages it serves under
`andreasehstandlicenseofclarityloc.github.io/augmanitai-portal/`.

Out of scope: third-party platforms (GitHub Pages infrastructure, Zenodo,
Wikidata, ORCID) — report those to the respective provider.

Thank you for helping keep the AUGMANITAI Research Programme safe.
